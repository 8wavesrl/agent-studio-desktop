# Eight Wave Agent Studio for Mac

The desktop app of Eight Wave Agent Studio: an agent you allow can read and use the apps on your
Mac when you ask it to, and you watch every step, pause it or stop it.

Download the latest version from [Releases](../../releases/latest), or from your Agent Studio
profile under "App per Mac", where you also find the link that connects the app to your agent.

- Requires macOS 14 or later on a Mac with Apple silicon.
- Signed with the Developer ID of 8 wave S.r.l. and notarized by Apple.

This repository holds only the releases.
